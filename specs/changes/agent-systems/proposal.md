# Secure design, agent systems, and usable modular installation

## Problem

The modular sources lack explicit agent-system design rules and a complete
local installation path. Organization packaging duplicates weaker validation.

## Goal

Implement the user's approved llm-agents proposal, the requested secure
design step, the aiscb-core.md name, and local installation with an optional
organization overlay, one catalog, and verified dependency loading.

## Non-goals

Do not change the approved aiscb-0.1.16 identity, publish or sign a release,
claim model-tested routing, or implement a remote gateway loader.

## Compatibility

Official modules share the core's release. The complete baseline remains a
generated compatibility artifact. Existing signed remote installation stays
on its published bundle until the maintainer completes release signing.
