# Concrete security attribution

## Problem

The core suppresses attribution for routine compliant work, leaving concrete
baseline-caused improvements invisible to users.

## Goal

Explain concrete baseline-caused security measures and their security benefit
briefly, grouping related improvements.

## Non-goals

No notice for checks without changes, no new residual-risk reporting, no version
change, and no changes to confirmation or refusal requirements.

## Compatibility

Existing attribution checks must allow and assess concrete security attribution
instead of rejecting it as routine. Source: the user approved this proposal and
its specification files on 2026-09-29 and requested English wording.
