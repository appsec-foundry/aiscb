# Decision-relevant security notices

## Problem

The web rule asks for a deployment instruction even for loopback-only work. The attribution rule and its tests demand an explanation for ordinary secure implementations.

## Goal

Explain actionable deviations, decisions and risks. Exercise the user's example of creating a small local test script with the established test runner.

## Non-goals

Changes to transport enforcement, approval requirements, module dependencies, release identifiers and installation are outside this change.

## Compatibility

Update expectations that previously required positive attribution for routine implementation. Preserve confirmation inside the actual question and the existing risk-reporting threshold.
