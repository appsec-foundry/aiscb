# Requirements

## NOTICE-001 Scope TLS instructions to exposure changes and plans

Source: the user's approved loopback and network-deployment recommendation, 2026-11-22, and aiscb-WEB-001.

Give the required TLS step when wider access is introduced or planned.

Acceptance: Loopback-only work receives no speculative deployment instruction. When work introduces or plans wider access, name the required TLS configuration. Wider binding still fails at startup without it.

## NOTICE-002 Attribute decision-relevant interventions

Source: the user's approved routine-attribution recommendation, 2026-11-22, and aiscb-ATTR-001 and aiscb-REPORT-001.

Attribute interventions that change the requested approach or require a decision. Apply routine secure defaults silently.

Acceptance: An ordinary secure implementation needs no baseline notice. A baseline-caused departure from the requested approach, refusal, blocker or required decision is attributed once. Confirmations name the baseline in the question. Report material residual risks under the existing reporting rule.

## NOTICE-003 Exercise an ordinary local test script

Source: the user's local test-script and unnecessary module-loading example and approval of the proposed regression, 2026-11-22.

Exercise the established local test runner and record both visible security commentary and loader calls.

Acceptance: The requested tests exercise both fixed inputs using existing tooling. They run successfully without a modular loader call, a security warning or an approval question. A test changing a security boundary remains subject to the existing matching rules.
