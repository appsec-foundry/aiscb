# Attribution names the baseline in words

## Problem

aiscb-ATTR-001 says to "name it" but does not say whether a rule ID counts.
Targeted model runs on 2026-10-03 cited rule IDs such as `aiscb-AUTH-001`
instead of naming the baseline, or attributed nothing; the attribution checks
require the name and reject rule citations alone.

## Goal

State that attribution names the aiscb baseline in words and that a rule ID
alone does not count.

## Non-goals

No change to when attribution is required, to confirmation, refusal or
Security note requirements, or to the attribution checks themselves.

## Compatibility

Existing checks already require the name; no case expectation changes.
Source: the user approved this proposal in the conversation on 2026-10-03.
