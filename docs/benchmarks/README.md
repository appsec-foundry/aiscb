# Benchmarks

Internal working notes on external benchmarks run against the baseline: what
runs, what is verified, what blocks the next step. How to run each target is
documented in [`tests/README.md`](../../tests/README.md); these notes do not
repeat it.

Each benchmark has one file here. Record verified state with its date and the
commit or evidence directory that shows it, so a later session can check it
instead of trusting it.
